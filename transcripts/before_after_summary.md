\# Before / After Summary — Xenna vs Rasa Demo



\## Observed Xenna pattern



In the public Xenna flow, selecting “Retourneren” routed the customer quickly toward a staff queue instead of answering a basic return question through self-service.



\## Rasa demo improvement



The Rasa demo assistant handles the same type of support journey conversationally:



\- answers the basic return question

\- handles opened-packaging follow-up

\- distinguishes damaged product from normal return

\- explains refund timing generically

\- handles missing-package guidance

\- routes to a medewerker only when order-specific review, photos, account details, or personal data are needed



\## Core value



This does not replace human support. It helps reduce avoidable support load by resolving common pre-handoff questions and reserving human agents for cases that genuinely need review.
